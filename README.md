# Roveo Plomberie Mons

Site web professionnel pour l'entreprise artisanale de plomberie et dépannage sanitaire Roveo à Mons (Belgique) et zone frontalière française.

## Pages incluses

- **Accueil** (`/`) : Présentation générale, bandeau d'urgence 24/7, simulateur de devis interactif, aperçu des prestations, avis clients et FAQ.
- **Services** (`/services`) : Fiches détaillées des prestations (dépannage d'urgence, recherche de fuite non destructive, débouchage haute pression, chauffe-eau & boilers, rénovation de salle de bain, robinetterie).
- **Zones d'intervention** (`/locations`) : Couverture du Grand Mons (Mons centre, Cuesmes, Jemappes, Ghlin, Nimy, Havré, etc.) et communes frontalières françaises avec filtre de recherche instantané.
- **À propos** (`/about`) : Histoire de l'entreprise, charte qualité, garanties décennales, certifications et outillage technique de pointe.
- **Contact** (`/contact`) : Formulaire de demande d'intervention, ligne d'urgence directe et consignes de sécurité en cas de sinistre des eaux.

## Caractéristiques techniques

- **Framework** : Astro 5 (Static Site Generation ultra rapide)
- **Design** : Palette moderne et responsive en Vanilla CSS
- **SEO local** : Données structurées JSON-LD Schema.org (Plumber / LocalBusiness), balises OpenGraph, Twitter Cards et géolocalisation
- **Accessibilité & Ergonomie** : Aucun emoji, aucune tiret cadratin, contrastes soignés et navigation fluide

## Développement local

```bash
# Installation des dépendances
npm install

# Démarrage du serveur de développement
npm run dev

# Construction du bundle de production
npm run build

# Prévisualisation de la production
npm run preview
```
